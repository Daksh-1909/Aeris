# AERIS

The existing front-end experience has been removed so you can replace it with your own app from zero.

This repository is now intentionally left in a neutral state for a new frontend implementation.

## Current state

- The Vite/React app and its generated assets have been deactivated.
- The project can now be rebuilt with your own stack and layout.
- Backend-related folders such as `supabase/` are left intact for database or service work.

## Next step

Create a new frontend from scratch in your preferred framework or plain HTML/CSS/JS and wire it into this repo as needed.
