## Sky journey clouds

The six cut-out sprites in `public/3d/clouds/cloud_{far,mid,near}_{1,2}.webp` are derived from these public domain cloud photographs:

- [Cumulus Cloud](https://commons.wikimedia.org/wiki/File:Cumulus_Cloud.jpg) — Hoodedwarbler12, public domain.
- [Single cloud on sky](https://commons.wikimedia.org/wiki/File:Single_cloud_on_sky.jpg) — Paolo Neo, public domain.
- [The sky is beautiful with cumulus clouds](https://commons.wikimedia.org/wiki/File:The_sky_is_beautiful_with_cumulus_clouds.jpg) — Nana Hemaa N.A., CC0.

Derivatives were cropped, resized, converted to transparent cut-outs, and encoded as WebP. Far sprites include a baked softening pass. The original color character is retained; the scene tint is a separate opacity overlay.
